EmbedLab Manager (Java console)

Kompilasi : javac -d out src/*.java
Jalankan  : java -cp out Main

Alur: Assistant membuat jadwal kelas -> Admin menyetujui -> Student memilih kelas dan absen.

Akun bawaan
admin01 / admin123      (Admin)
asisten01 / asisten123  (Assistant)
asisten02 / asisten123  (Assistant)
mhs01 / mhs123          (Student)
mhs02 / mhs123          (Student)
